# personal-website

My personal website: a simple static site, plain HTML and CSS with no build step.

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Edit

- `index.html`: content (name, intro, projects, contact)
- `styles.css`: colors, fonts, layout (it switches to dark mode automatically)

## Deploy

Any static host works: Netlify, Vercel, Cloudflare Pages, or GitHub Pages
(GitHub Pages on a private repo needs a paid GitHub plan).
