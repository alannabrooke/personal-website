# Custom icons

Drop icon images here (square PNG, SVG or WebP, about 512×512) and point to them
from `customIcons` in `src/data/content.ts`, e.g. `finder: "/icons/finder.png"`.

Names you can override: `finder`, `notes`, `mail`, `preview`, `terminal`,
`trash`, `github`, `linkedin`. Any you leave out keep the built-in drawn icon.

Only use icons you made or have a license to use on a website.
